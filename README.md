# 🚀 Personal Portfolio – Ayyappan Jijo

This is my personal portfolio website built to showcase my skills, experience, and projects in a modern and interactive way.

## ✨ Features

- 🎯 Clean and responsive UI design
- 🔥 Glassmorphism-based modern interface
- 📊 Animated skill bars for visualizing technical expertise
- 📁 Automatic GitHub project integration using GitHub API
- 🎬 Smooth scroll reveal animations
- 🌌 Dynamic background that changes automatically
- 📄 Resume section with **View & Download CV**
- 🧭 Active navigation highlight while scrolling

## 🛠️ Tech Stack

- HTML5  
- CSS3 (Flexbox, Grid, Glassmorphism)  
- JavaScript (DOM Manipulation, Fetch API)
